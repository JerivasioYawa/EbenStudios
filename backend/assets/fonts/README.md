# Invoice PDF fonts

Noto Sans Regular and Bold are bundled so invoice PDFs do not depend on installed
operating-system fonts. The fonts cover Latin, Greek and Cyrillic text, including
common accented customer/product names. Other scripts need an appropriate font.

Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans),
commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Distributed under the bundled
[SIL Open Font License](OFL.txt). These files are unmodified.
